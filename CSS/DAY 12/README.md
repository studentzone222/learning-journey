Topics Covered
✅ Parts of a CSS Rule
Selector
Declaration Block
Property
Value
✅ Default Browser Styles
Browsers apply default CSS automatically.
✅ Universal Selector (*)
Selects all elements.
Has the lowest specificity (0).
✅ Selecting List Items
ol li {} → Targets <li> inside an ordered list.
ul li {} → Targets <li> inside an unordered list.
✅ CSS Box Model
Content
Padding
Border
Margin
✅ Block-Level Elements
Start on a new line.
Take up the full available width by default.
Examples: div, p, section.
✅ Inline-Block Elements
Behave like inline elements.
Can have width and height.
✅ !important Keyword
Overrides normal CSS specificity.
✅ Inline-Level Elements
Do not start on a new line.
Only take up the space they need.
Examples: span, img.
✅ Internal CSS
Written inside the <style> tag within the <head> element.
✅ Padding Shorthand
Order: Top → Right → Bottom → Left (TRBL)
✅ Margin Shorthand
Order: Top → Right → Bottom → Left (TRBL)
✅ Inline CSS
Applied directly to an HTML element using the style attribute.
✅ Default width Value
width: auto;
